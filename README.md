## Overview

This repository hosts the source code for my personal SQA Engineer portfolio website. It highlights my hands-on experience in **Manual Testing, API Validation, and Test Automation**, along with my academic background in Computer Science and Engineering (CSE) and practical development projects.

The portfolio is designed with a responsive, multi-page architecture focusing on clean UI/UX, interactive animations, and straightforward navigation for recruiters and engineering teams.
